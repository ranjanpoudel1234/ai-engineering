### What to Focus On

- What a vector is, why similar text → similar vectors, cosine similarity
- Chunking default: `RecursiveCharacterTextSplitter` with `chunk_size=500`, `chunk_overlap=50`
- Tag every chunk with metadata (source, page, section, date) at ingestion time
- Two-stage pattern: embed + search (fast) → rerank top-k (accurate)
- Common retrieval failures: semantic drift, chunk boundaries, missing metadata, top-k too small
- Prompt the model to only answer from provided context, say "I don't know" when not present
- Pass chunk metadata into prompt and instruct model to reference sources

### What to Focus On

- Perceive → plan → act → observe loop; how it terminates; what happens when a tool fails

- `TypedDict` state schemas, reducers for parallel updates, checkpointing, human-in-the-loop pauses
- Max iteration limits, per-tool retry with backoff, catching exceptions without crashing agent
- Decision framework: single prompt → workflow → agent (only if steps are unpredictable)
- Prompt chaining, routing, parallelization, orchestrator-subagent patterns
- Golden test set of 20-50 inputs; deterministic + LLM-as-judge scoring; run evals on every change
- Process metrics (right tool called?) vs outcome metrics (task succeeded?)
